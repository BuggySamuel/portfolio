Waarom dit project?

Op school krijg ik het vak besturingsystemen waar dingen zoal hoe computers werken, hoe je software op een computer zet en hoe je een computer beheerd. Ik vondt dit heel inttresant dus heb ik van een kleine kantoor computer een server gemaakt waarop mijn egien cloud opslag, muziek en films host.

Wat leerde ik door dit project?

Tijdens dit project leerde ik hoe ik een server instel voor gebruik in selfhosting en beetje over hoe je een netwerk configureert.

Voor het besturingsystemen gebruik ik linux debian, omdat ik het gebruikte op school. Voor de opslag cloud gebruik samba, voor muziek en films jellyfin en als thuis automatisathie platform gebruik ik homeassitant. Al deze software is opensource en gratis.

De behuizing is een 3d print die ik van het internet heb gedownload en zelf heb geprint.
De computer is een HP ProDesk 400 G1
De switch is een tp link TL-SG108
De router is een mikrotik hex s(2025) en is er nog de optische schijf voor jellyfin, een hardeschijf en een stekkerdoos.
